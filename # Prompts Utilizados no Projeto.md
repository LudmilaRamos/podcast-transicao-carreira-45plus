# Prompts Utilizados no Projeto

## 🎯 Prompt para criação do roteiro
"Crie um roteiro de podcast sobre transição de carreira após os 45 anos, destacando os impactos emocionais desse processo. Use tom acolhedor, humano, realista e motivador. Estruture em introdução, desenvolvimento e fechamento."

## 🎤 Prompt para geração do áudio no ElevenLabs
"Use voz feminina adulta e madura (35–45 anos), tom acolhedor, natural e confiante. Leia o roteiro como um episódio de podcast, com ritmo equilibrado, pausas suaves e entonação emocional leve."

## 🧩 Prompt para refinar texto
"Reescreva este texto mantendo o sentido, mas deixando mais claro, fluido e profissional, com foco em podcast narrativo."

## 🎨 Prompt para capa (Midjourney ou IA similar)
"Criar uma capa de podcast com foco no tema 'Transição de carreira após os 45 anos e saúde mental'. Estilo minimalista, profissional, acolhedor. Cores suaves, tons humanizados."
